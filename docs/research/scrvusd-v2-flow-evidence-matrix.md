# Witnessed v2 flow evidence matrix

`scripts/research/scrvusd-v2-flow-evidence-matrix.mjs` builds a versioned research matrix. Call `readV2FlowEvidenceMatrix({ pool, asOfUtc, horizons: [3600, 7200, ...] })` to verify retained issue and score bytes against the database before projection. `buildV2FlowEvidenceMatrix({ labels, horizons })` is the pure reducer for tests and already verified reader output; it does not authenticate caller-supplied rows on its own. It refuses the older retrospective label schema.

Each requested horizon uses the witnessed evaluator's exact rule: an issued arm enters only when its scheduled target is within `[runVisibleAtUtc + H, runVisibleAtUtc + H + 300 seconds]`. The result retains the witnessed four-arm denominator, eligible issued count, target abstentions, point-score outcome statuses, exact issue reference, holder, size, direct route, anchor block, target, and certified minimum publication lead. It keeps the first-loss interval on both issue-time and witness-time clocks, plus baseline sample age and the `currentAtDecision: unverified` flag. Dependency components are recomputed for each requested horizon from shared anchors or overlapping capture windows. They are not an independent episode count.

For each eligible issue, the frozen `historicalFlowContext` contributes four distinct covariates: maximum observed complete-window gross withdrawals and maximum observed complete-window **signed** net depletion, each at 24 hours and seven days. Each maximum keeps its own raw crvUSD amount and window start/end. A negative signed maximum remains negative; the gross and net maximizing windows may differ. Observed windows must fit within the validated coverage and its issue-time evidence cutoff. Missing context or incomplete windows produce explicit unavailable reasons, counted per feature and per requested horizon. `completeFourFeatureRows` counts rows with all four features observed; it is not a forecast sample size or independent count.

The historical flow ledger records successful scrvUSD vault Deposit and Withdraw events, including certified quiet ranges in a contiguous receipt prefix. It does not record attempted exits, holder transaction execution, secondary-route fills, latent withdrawal demand, a protocol maximum, or future cash runway. The matrix leaves probability, likely exit-condition duration, shrinking-ability alerts, and continuous availability unavailable. The witnessed reader covers DB-witnessed runs at the as-of cutoff; scheduled slots that never reached a run witness remain outside its denominator. Source capture start times are self-reported, and chronological backtest eligibility remains false.

Run the focused checks with `node --test scripts/research/scrvusd-v2-flow-evidence-matrix.test.mjs`.
