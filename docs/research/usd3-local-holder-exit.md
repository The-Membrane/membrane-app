# USD3 local holder exit observations

Frozen route: `USDC → USD3 [USDC]`, vault `0x056b269eb1f75477a8666ae8c7fe01b64dd55ecc`, original USDC `0xa0b86991c6218b36c1d19d4a2e9eb0ce3606eb48`.

The Mac issue job selects a receipt-screened EOA with USD3 shares at a recent finalized Ethereum block. Two independent RPC origins must agree on the baseline and the USD3 proxy implementation. It freezes the selected holder, a six-case exact USDC amount ladder, and H1/H4/H24/H48/H168 target and capture deadline clocks in a private SHA-linked issue record. Each baseline case uses same-holder `withdraw(Q,holder,holder)` simulation and share coverage evidence. A successful simulation establishes only executability at that block; it is not a mined USDC payout.

The score job follows baseline-success and covered-baseline-revert exact holder/Q cases as separate cohorts. It selects the first finalized block crossing each target from two independent origins and replays the exact call. An impaired baseline can yield sampled simulated recovery, continued revert, holder attrition, or censoring; recovery is known only between two observation targets. A missed capture window is sealed only after two finalized RPC origins agree that chain time passed the deadline. Attempt receipts record each native run and link new issue or score seals without exposing holder or amount. Every local record remains private under `data/research/venue-signals/carry-public-usd3-exit-*`.

The local development API returns only coarse route/horizon counts after verifying the USD3 issue and score chains. The count unit is correlated Q cases; repeated sizes in one issue are one holder episode. New issues exclude previously sampled holders; when the bounded scan finds no fresh holder, an attempt records `no_fresh_holder` without sealing a duplicate issue. No probability, likely restriction duration, current user exit guarantee, or forecast is published from these samples. This lane can eventually support calibration only after enough scored, independent holder episodes and historically complete competing-flow evidence exist.

The native wrappers are `scripts/carry-public-usd3-exit-tick.sh issue|score`, with issue at minute 31 and score at minutes 6/16/26/36/46/56; minute 36 is deferred to give the issue run room. The old Neon USD3 H1 stages are removed from `scripts/carry-cash-observation-tick.sh`. The issue, score, and attempt chains can be verified with each research script's `--verify` mode; no Neon connection is needed.
