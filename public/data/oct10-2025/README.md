# Oct 10–11 2025 stress window — measured dataset

Generated by `pnpm build:oct10-data` (`scripts/build-oct10-dataset.ts`).
**Do not hand-edit these files.** Regenerate them.

Window: `2025-10-10T00:00:00Z` → `2025-10-11T23:59:00Z`, 1-minute grid, 2,880 bars.

## Files

- **`prices-1m.json`** — columnar price series. Chainlink oracle (ETH/USD, BTC/USD,
  stETH/ETH), Binance spot with candle lows (ETH, BTC, USDe), on-chain USDe (Curve quote).
  `carried` flags mark minutes where an oracle held its previous round rather than
  printing a new one. **Nulls are genuine gaps and are never forward-filled in storage.**
- **`protocols.json`** — Aave V3 reserve parameters and Morpho Blue market parameters read
  on-chain at mainnet block **23,543,615**; the measured Aave/Morpho liquidation repay
  distributions; the oracle-lag report; the USDe exit-liquidity summary.
- **`manifest.json`** — window, per-series attribution, and the caveat list the UI renders.

## Provenance

Fetched from public JSON-RPC (Tenderly public gateways) and Binance public daily dumps.
No paid API keys. The raw pull lives at `~/Downloads/oct10_data` and is **not committed**;
its own `SOURCES.md` documents endpoint verification (fallback endpoints admitted only
after returning byte-identical results on a sample) and `FINDINGS.md` the analysis.

## Caveats that change conclusions

1. **The feed labelled `wstETH/ETH` is the stETH/ETH feed.** Its on-chain `description()`
   reads `STETH / ETH` and it is a ~24-hour-heartbeat series. Shipped under its true
   identity; not used to price wstETH.
2. **The on-chain USDe low is a marginal quote, not exit liquidity.** $0.99683 is the price
   for a 1 USDe clip. The same pool bottomed at $1.13M USDC of reserves, and a 1,000,000
   USDe sell realised an average of $0.9759 at the worst minute.
3. **"$0.9957" is not in this data.** A prior session recorded that as the on-chain USDe
   minimum. It appears only as a pre-existing assumption in a source-script comment, never
   as a measured output. The measured minimum is **$0.99683** at 2025-10-10 22:56 UTC.
4. **Oracle ≠ spot, and the gap has a sign.** During the crash the ETH oracle printed
   0.70% *below* the Binance spot trough (same minute); the BTC oracle bottomed 4 minutes
   late and 1.14% *above* it. A model keyed off spot fires ETH liquidations late and BTC
   liquidations early. Liquidations fire off the oracle — use the oracle columns.
5. **Aave's close factor is documented, not on-chain readable.** Use the measured repay
   distribution instead: it is what liquidators actually did.
